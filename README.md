# Utilora

Free, browser-first online tools for everyday work.

**Live website:** https://utilora-ten.vercel.app/

## Current milestone

Utilora currently includes **50 working tools** across Text, Developer, Calculator and Security categories. Each tool has a dedicated guide page with unique metadata, usage steps, examples, FAQ content and structured data.

## Stack
- Next.js App Router + TypeScript
- Tailwind CSS
- Lucide icons
- Vercel deployment

## Local development
```bash
npm install
npm run dev
```

## Quality checks
```bash
npm run typecheck
npm run build
```

## Project principles
- Ship genuinely working tools, not placeholder cards.
- Prefer browser-side processing for privacy and low operating costs.
- Keep the experience accessible, responsive and fast.
- Give each tool a useful page with clear instructions and examples.
- Add tools in tested batches rather than publishing empty pages.

## SEO foundation
- Per-tool metadata and canonical URLs
- XML sitemap containing all current tool pages
- robots.txt
- Open Graph and Twitter metadata
- WebApplication and FAQ structured data on tool pages
- Related-tool internal links

## Roadmap
Grow from 50 to 100, then 500+ tools while testing every new utility and keeping pages useful and distinct. AdSense approval is not guaranteed; content quality, site policies and eligibility must be reviewed before applying.

Utilora is an independent project. The repository name remains IdeaBridge for now.
