# Utilora

Free, privacy-minded online tools for everyday work.

## Stack
- Next.js App Router + TypeScript
- Tailwind CSS
- Vercel deployment

## Local development
```bash
npm install
npm run dev
```

## Project principles
- Ship genuinely working tools, not placeholder pages.
- Prefer browser-side processing for privacy and low operating costs.
- Keep the experience accessible, responsive and fast.
- Publish useful, original guidance for each tool.

Utilora is an independent project. The repository name remains IdeaBridge for now.
